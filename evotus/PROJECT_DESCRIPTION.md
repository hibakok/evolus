# EVOTUS - Проект эволюционирующей нейронной сети
## Универсальный аппроксиматор функций с полностью эволюционирующей архитектурой

## Описание проекта

EVOTUS - это универсальная нейронная сеть с эволюционными стратегиями, оптимизированная для максимальной скорости эволюции и универсальности аппроксимации любых вычислимых функций. Проект реализует двухпопуляционный подход к эволюции нейронных сетей с расширенными возможностями.

## Ключевые улучшения для универсальности аппроксиматора

### 1. Расширенный набор функций активации (18 типов)
Теперь поддерживаются следующие функции активации:
- **Базовые**: sigmoid, tanh, relu, linear, step
- **Продвинутые**: gaussian, swish, gelu, elu, softplus
- **Периодические**: sin, cos, sinc
- **Специализированные**: rbf, bipolar_sigmoid
- **Волновые**: triangular, sawtooth, square_wave

Это позволяет аппроксимировать широкий класс функций включая периодические, разрывные и сложные нелинейные зависимости.

### 2. Полностью эволюционирующая архитектура связей
**Важное изменение**: В программе больше нет заранее заданных конструкций или специальных типов связей (например, "рекуррентные связи" как отдельная сущность). 

Все связи между нейронами равноправны и эволюционируют без ограничений:
- Каждый нейрон может быть связан с любым другим нейроном
- Связи могут идти в обоих направлениях одновременно (от нейрона 1 к нейрону 2 и от нейрона 2 к нейрону 1)
- Связи не дублируются - каждая пара (from_neuron, to_neuron) уникальна
- Саморекуррентные связи (нейрон на себя) также возможны и эволюционируют наравне со всеми

Такой подход обеспечивает:
- Максимальную гибкость архитектуры
- Отсутствие заранее заданных ограничений на структуру сети
- Полную эволюционность всех компонентов системы

### 3. Улучшенные мутации (8 типов)
1. Изменение веса связи
2. Добавление связи между любыми двумя нейронами
3. Удаление связи
4. Добавление нейрона
5. Удаление нейрона
6. Изменение биаса нейрона
7. **Изменение функции активации** (критически важно для универсальности)
8. **Мутация нескольких весов одновременно** (для быстрого исследования пространства)

Удалена отдельная мутация "добавление рекуррентной связи", так как теперь все связи равноправны и добавляются через общую мутацию добавления связи.

### 4. Улучшенный forward pass
- Увеличено количество итераций для сходимости сетей с любыми связями (20 итераций)
- Добавлено плавное обновление значений нейронов для стабильности
- Поддержка любых связей между нейронами без ограничений

### 5. Улучшенная инициализация
- Увеличено начальное количество скрытых нейронов (4 → 6-8)
- Разнообразные функции активации при инициализации
- Случайные связи между всеми нейронами при старте (включая саморекуррентные)

## Архитектура

### Две популяции

1. **Внутренняя популяция (прародители)**
   - Размер определяется параметром `population_size` в config.txt
   - Особи НЕ мутируют напрямую
   - В каждом поколении остаются неизменными (за исключением замены лучшими потомками)
   - Служат основой для создания потомков
   
2. **Внешняя популяция (потомки)**
   - Создаётся в каждом поколении из особей внутренней популяции
   - Каждая особь внутренней популяции порождает N потомков (параметр `offspring_per_individual`)
   - Потомки создаются путём применения мутаций к прародителям
   - Количество мутаций на потомка настраивается через `outer_population_mutations`
   - Потомки оцениваются по fitness function
   - Лучший потомок может заменить своего прародителя во внутренней популяции (только если он строго лучше)

### Принцип работы эволюции

1. В начале поколения внутренняя популяция прародителей неизменна
2. Каждый прародитель порождает N потомков (мутантов) во внешнюю популяцию
3. Потомки оцениваются по всем парам вход-выход из обучающих данных
4. Лучший потомок сравнивается со своим родителем
5. Потомок заменяет родителя ТОЛЬКО если он строго лучше:
   - Меньшая ошибка всегда лучше
   - При РАВНОЙ ошибке выбирается особь с меньшей сложностью
   - Если более сложная особь имеет ХОТЯ БЫ ЧУТЬ меньшую ошибку - она лучше
6. Сравнение производится напрямую без штрафов за сложность

## Мутации

Реализовано 8 типов минимальных мутаций:
1. Изменение веса связи нейронов
2. Добавление связи между любыми двумя нейронами
3. Удаление связи между нейронами
4. Добавление нейрона
5. Удаление нейрона
6. Изменение биаса нейрона
7. Изменение функции активации (выбор из 18 типов)
8. Мутация нескольких весов одновременно

Все связи эволюционируют без ограничений - нет отдельных мутаций для "рекуррентных" связей, так как все связи равноправны.

Масштаб мутаций определяется количеством одновременных случайных мелких мутаций (`num_mutations` параметр в методе `mutate()`).

## Структура нейронной сети

### Neuron (Нейрон)
- `id`: уникальный идентификатор
- `activation`: функция активации (18 типов на выбор)
- `bias`: смещение нейрона

### Connection (Связь)
- `from_neuron`: ID нейрона-источника
- `to_neuron`: ID целевого нейрона
- `weight`: вес связи

### Individual (Особь)
- `neurons`: словарь нейронов по ID
- `connections`: список связей (любые связи между нейронами, включая саморекуррентные)
- `fitness`: приспособленность (ошибка)
- `complexity`: сложность (количество связей)
- `input_size`: количество входов
- `output_size`: количество выходов

## Файлы проекта

- `main.py` - основной код программы
- `config.txt` - файл конфигурации с настраиваемыми параметрами
- `data.txt` - обучающие данные (формат: входные значения | выходные значения)
- `population.json` - сохранённая популяция (автоматически создаётся/загружается)

## Настройка параметров

Все параметры настраиваются через файл `config.txt`:
- `population_size` - размер внутренней популяции
- `offspring_per_individual` - количество потомков от каждой особи
- `outer_population_mutations` - количество мутаций для потомков внешней популяции
- `mutations_per_offspring` - количество мутаций для внутренней популяции
- `weight_mutation_std` - стандартное отклонение для мутации весов
- `min_mutation_std` / `max_mutation_std` - границы адаптивной мутации
- `initial_hidden_neurons` - начальное количество скрытых нейронов

## Запуск программы

```bash
python main.py
```

Программа предоставляет интерактивное меню:
1. Начать эволюцию
2. Тестировать текущую лучшую особь
3. Просмотреть статус популяции
4. Сохранить популяцию
5. Загрузить популяцию
6. Настройки
7. Просмотреть/редактировать обучающие данные
8. Экспортировать лучшую особь в файл
9. Импортировать особь из файла
0. Выход

## Важные ограничения

**Особи во внутренней популяции НЕ могут мутировать напрямую!**
- Они могут лишь порождать особей-потомков во внешнюю популяцию
- Замена особи во внутренней популяции происходит только через замену лучшим потомком
- Прямое редактирование внутренней популяции возможно только через импорт особи (функция import_individual)

## Теоретическая универсальность

Благодаря следующим улучшениям, данный аппроксиматор приближается к универсальному аппроксиматору любых вычислимых функций:

1. **Разнообразные функции активации**: 18 типов позволяют аппроксимировать широкий спектр функций
2. **Полностью эволюционирующая архитектура связей**: все связи между нейронами равноправны и эволюционируют без заранее заданных ограничений
3. **Адаптивная архитектура**: эволюция может добавлять/удалять нейроны и связи
4. **Эволюция функций активации**: каждый нейрон может изменить свою функцию активации в процессе эволюции

Это соответствует теореме об универсальной аппроксимации и приближает сеть к возможности вычисления любой вычислимой функции (Turing completeness при наличии любых связей между нейронами).
