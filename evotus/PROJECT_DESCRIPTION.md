# EVOTUS - Проект эволюционирующей нейронной сети

## Описание проекта

EVOTUS - это универсальная нейронная сеть с эволюционными стратегиями, оптимизированная для максимальной скорости эволюции. Проект реализует двухпопуляционный подход к эволюции нейронных сетей.

## Архитектура

### Две популяции

1. **Внутренняя популяция (прародители)**
   - Размер определяется параметром `population_size` в config.txt
   - Особи НЕ мутируют напрямую
   - В каждом поколении остаются неизменными (за исключением замены лучшими потомками)
   - Служат основой для создания потомков
   
2. **Внешняя популяция (потомки)**
   - Создаётся в каждом поколении из особей внутренней популяции
   - Каждая особь внутренней популяции порождает N потомков (параметр `offspring_per_individual`)
   - Потомки создаются путём применения мутаций к прародителям
   - Количество мутаций на потомка настраивается через `outer_population_mutations`
   - Потомки оцениваются по fitness function
   - Лучший потомок может заменить своего прародителя во внутренней популяции (только если он строго лучше)

### Принцип работы эволюции

1. В начале поколения внутренняя популяция прародителей неизменна
2. Каждый прародитель порождает N потомков (мутантов) во внешнюю популяцию
3. Потомки оцениваются по всем парам вход-выход из обучающих данных
4. Лучший потомок сравнивается со своим родителем
5. Потомок заменяет родителя ТОЛЬКО если он строго лучше:
   - Меньшая ошибка всегда лучше
   - При РАВНОЙ ошибке выбирается особь с меньшей сложностью
   - Если более сложная особь имеет ХОТЯ БЫ ЧУТЬ меньшую ошибку - она лучше
6. Сравнение производится напрямую без штрафов за сложность

## Мутации

Реализовано 6 типов минимальных мутаций:
1. Изменение веса связи нейронов
2. Добавление связи между нейронами
3. Удаление связи между нейронами
4. Добавление нейрона
5. Удаление нейрона
6. Изменение биаса нейрона

Масштаб мутаций определяется количеством одновременных случайных мелких мутаций (`num_mutations` параметр в методе `mutate()`).

## Структура нейронной сети

### Neuron (Нейрон)
- `id`: уникальный идентификатор
- `activation`: функция активации (sigmoid, tanh, relu, linear, step)
- `bias`: смещение нейрона

### Connection (Связь)
- `from_neuron`: ID нейрона-источника
- `to_neuron`: ID целевого нейрона
- `weight`: вес связи

### Individual (Особь)
- `neurons`: словарь нейронов по ID
- `connections`: список связей
- `fitness`: приспособленность (ошибка)
- `complexity`: сложность (количество связей)
- `input_size`: количество входов
- `output_size`: количество выходов

## Файлы проекта

- `main.py` - основной код программы
- `config.txt` - файл конфигурации с настраиваемыми параметрами
- `data.txt` - обучающие данные (формат: входные значения | выходные значения)
- `population.json` - сохранённая популяция (автоматически создаётся/загружается)

## Настройка параметров

Все параметры настраиваются через файл `config.txt`:
- `population_size` - размер внутренней популяции
- `offspring_per_individual` - количество потомков от каждой особи
- `outer_population_mutations` - количество мутаций для потомков внешней популяции
- `mutations_per_offspring` - количество мутаций для внутренней популяции (резервный параметр)
- `weight_mutation_std` - стандартное отклонение для мутации весов
- `min_mutation_std` / `max_mutation_std` - границы адаптивной мутации
- `initial_hidden_neurons` - начальное количество скрытых нейронов

## Запуск программы

```bash
python main.py
```

Программа предоставляет интерактивное меню:
1. Начать эволюцию
2. Тестировать текущую лучшую особь
3. Просмотреть статус популяции
4. Сохранить популяцию
5. Загрузить популяцию
6. Настройки
7. Просмотреть/редактировать обучающие данные
8. Экспортировать лучшую особь в файл
9. Импортировать особь из файла
0. Выход

## Важные ограничения

**Особи во внутренней популяции НЕ могут мутировать напрямую!**
- Они могут лишь порождать особей-потомков во внешнюю популяцию
- Замена особи во внутренней популяции происходит только через замену лучшим потомком
- Прямое редактирование внутренней популяции возможно только через импорт особи (функция import_individual)
